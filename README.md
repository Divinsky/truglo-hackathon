# TruGlo

TruGlo is relationship intelligence—not dating: a friend joins a live agent session, the agent proposes red-flag notes, and a person approves before anything is written onto another human.

## Demo

Open `demo/index.html` in a browser.

- **Observe:** watch the `propose_red_flag` tool trace and its `pending_approval` status.
- **Control:** approve or reject before anything is written onto another person.
- **Test:** repeat the flow; the reject path leaves nothing written.

This repository contains the hackathon demo and the `trueglow-mcp` MCP server.
